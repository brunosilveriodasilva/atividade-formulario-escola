Atividade de HTML e CSS — Formulário
Descrição

Esta atividade tem como objetivo criar um formulário utilizando HTML5 e CSS3.

Objetivo

Praticar a criação e estilização de formulários em páginas web, utilizando diferentes tipos de campos e elementos HTML.

Tecnologias utilizadas

HTML5

CSS3

Elementos do formulário

O formulário deverá conter:

Nome completo

E-mail

Senha

Data de nascimento

Telefone

Sexo

Cidade

Estado

Mensagem

Botão de enviar

Botão de limpar

Estrutura do projeto
atividade-formulario/
├── index.html
└── style.css

Como executar

Baixe ou clone o projeto.

Abra o arquivo index.html em um navegador.

Preencha os campos do formulário para visualizar seu funcionamento.

Objetivo da atividade

Desenvolver conhecimentos básicos de HTML e CSS, aprendendo a estruturar uma página e aplicar estilos aos elementos de um formulário.
